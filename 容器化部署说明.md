# 容器化部署说明

## 当前项目状态

本项目是一个 **Java 基础学习项目**，主要包含：
- `_01base`: Java 基础语法练习（变量、控制流、数组、方法等）
- `_02object`: 面向对象编程练习（类、对象、封装等）

**重要说明：** 当前项目为纯 Java 学习代码，**不包含任何 Web 服务或 API 接口**，因此：
- ❌ 没有 HTTP 路由端点
- ❌ 没有 RESTful API
- ❌ 没有 Web 服务器配置
- ❌ 没有 Docker 容器化配置

## 容器化部署的路由和入参

由于本项目是学习型项目，没有 Web 服务，因此：

### 当前状态：
**没有路由和入参可供容器化部署使用**

### 如需容器化部署，需要先完成以下工作：

#### 1. 添加 Web 框架
需要将项目改造为 Web 应用，可选择：
- **Spring Boot** (推荐)
- Servlet 容器（如 Tomcat）
- 其他 Java Web 框架

#### 2. 定义 API 路由
示例 Spring Boot 控制器：
```java
@RestController
@RequestMapping("/api")
public class ExampleController {
    
    // GET 请求示例
    @GetMapping("/hello")
    public String hello(@RequestParam(required = false) String name) {
        return "Hello, " + (name != null ? name : "World");
    }
    
    // POST 请求示例
    @PostMapping("/data")
    public ResponseEntity<?> createData(@RequestBody DataRequest request) {
        // 处理逻辑
        return ResponseEntity.ok("Data received");
    }
}
```

#### 3. 创建 Dockerfile
示例 Dockerfile：
```dockerfile
FROM openjdk:11-jre-slim
WORKDIR /app
COPY target/*.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

#### 4. 创建 docker-compose.yml
示例配置：
```yaml
version: '3.8'
services:
  java-app:
    build: .
    ports:
      - "8080:8080"
    environment:
      - SPRING_PROFILES_ACTIVE=prod
```

## 如何改造为可容器化的 Web 应用

### 步骤 1: 添加 Spring Boot 依赖
创建 `pom.xml`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
         http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    
    <groupId>com.example</groupId>
    <artifactId>java-learn</artifactId>
    <version>1.0.0</version>
    
    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>2.7.0</version>
    </parent>
    
    <dependencies>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>
    </dependencies>
    
    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>
</project>
```

### 步骤 3: 定义路由和入参

#### 示例路由表：

| 方法 | 路由 | 入参 | 说明 |
|------|------|------|------|
| GET | `/api/health` | 无 | 健康检查 |
| GET | `/api/hello` | `name` (可选) | 问候接口 |
| POST | `/api/calculate` | `{number1: int, number2: int, operation: string}` | 计算接口 |
| GET | `/api/person/{id}` | `id` (路径参数) | 获取人员信息 |
| POST | `/api/person` | `{name: string, age: int}` | 创建人员信息 |

#### 实现示例：
```java
@RestController
@RequestMapping("/api")
public class LearnController {
    
    @GetMapping("/health")
    public Map<String, String> health() {
        return Map.of("status", "UP", "timestamp", new Date().toString());
    }
    
    @PostMapping("/calculate")
    public Map<String, Object> calculate(@RequestBody CalculateRequest request) {
        int result = switch(request.getOperation()) {
            case "add" -> request.getNumber1() + request.getNumber2();
            case "subtract" -> request.getNumber1() - request.getNumber2();
            case "multiply" -> request.getNumber1() * request.getNumber2();
            case "divide" -> request.getNumber1() / request.getNumber2();
            default -> 0;
        };
        return Map.of("result", result);
    }
}

// DTO 类
class CalculateRequest {
    private int number1;
    private int number2;
    private String operation;
    // getters and setters
}
```

### 步骤 4: 容器化部署

#### 构建镜像：
```bash
mvn clean package
docker build -t java-learn:latest .
```

#### 运行容器：
```bash
docker run -d -p 8080:8080 --name java-learn-app java-learn:latest
```

#### 测试路由：
```bash
# 健康检查
curl http://localhost:8080/api/health

# 问候接口
curl http://localhost:8080/api/hello?name=张三

# 计算接口
curl -X POST http://localhost:8080/api/calculate \
  -H "Content-Type: application/json" \
  -d '{"number1": 10, "number2": 5, "operation": "add"}'
```

## 总结

**当前项目状态：** 纯 Java 学习项目，无 Web 服务，无路由，无法直接容器化部署。

**如需容器化部署：** 需要先将项目改造为 Web 应用（如添加 Spring Boot），然后定义 API 路由和入参，最后创建 Docker 配置文件。

**建议：** 
1. 如果只是学习 Java 基础，保持当前结构即可
2. 如果需要学习 Web 开发和容器化部署，建议按照上述步骤进行改造
3. 可以创建新的分支进行 Web 应用改造，保留主分支的学习代码
